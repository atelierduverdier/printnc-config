# tool_icons.txt — quel dessin pour quel outil, dans le panneau TOOL.
#
# Format : <numero d'outil>:<fichier .png de ce dossier>
# Les lignes vides et tout ce qui suit un # sont ignores. Le fichier livre
# par LinuxCNC n'admettait ni l'un ni l'autre, et associait les numeros de
# QUELQU'UN D'AUTRE : son T1 etait une fraise hemispherique, le notre est un
# emplacement manuel sans description. Il aurait donc menti a chaque outil.
# L'original reste dans /usr/share/qtvcp/screens/qtdragon_hd/images/tool_icons/.
#
# CE QUI N'EST PAS ICI N'EST PAS UNE ERREUR : un outil absent de cette liste
# affiche `inconnu.png`, gris et tirete — « un outil est monte, on ignore ce
# qu'il coupe ». Dire « pas d'outil » pour un outil qu'on ne sait pas nommer
# serait une fausse alarme. `aucun.png` est reserve a T0, ou il est exact.
#
# LES DESSINS SONT LES NOTRES, en vectoriel dans source/*.svg, rendus en PNG
# par `python3 outils/faire_theme.py`. Editer le SVG a Inkscape puis relancer.
# Leur grammaire : l'ORANGE marque la partie coupante, et seulement quand on
# sait la nommer ; la pince et la queue sont communes a tous les dessins,
# c'est ce qui rend la partie basse comparable d'un outil a l'autre.
#
# Disponibles : fraise_droite, fraise_demi_ronde, fraise_v, foret,
#               surfaceuse, palpeur, laser, inconnu, aucun.
#
